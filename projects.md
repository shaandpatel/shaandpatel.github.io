#### [AuroraNet](https://github.com/shaandpatel/AuroraNet)
End-to-end LSTM pipeline for **real-time aurora forecasting**, from raw space weather data ingestion to interactive dashboard deployment.

#### [LedgerLens](https://github.com/shaandpatel/LedgerLens)
Anomaly-driven financial investigation workstation that isolates SEC 10-K reporting discrepancies using hybrid retrieval and cross-encoder reranking, generating evidence-grounded disclosures via local LLM orchestration and structured JSON schemas.

<p>&nbsp;</p>

#### [SolarWindLakehouse](https://github.com/shaandpatel/solar-wind-lakehouse)

End-to-end Databricks and **PySpark Medallion Lakehouse** that processes **solar wind data** through automated data quality routing and runs MLflow-tracked KMeans anomaly detection.

<p>&nbsp;</p>

#### [DefCoordML](https://github.com/shaandpatel/DefCoordML)
**AI-powered NFL Defensive Coordinator**, designed to anticipate whether the offense will **pass** or **rush** before the snap.
